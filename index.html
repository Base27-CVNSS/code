Tài liệu đầy đủ ↗
01

Chọn & kiểm tra

Xem công nghệ, danh sách chức năng, giấy phép và bản demo trước khi chọn mã nguồn.

02

Chạy trên máy

Tải repo, chạy npm run dev và mở localhost:8080. Không cần cài thư viện.

03

Cấu hình cửa hàng

Sửa danh mục trong products.json, thay hình ảnh và thiết lập kênh liên hệ người bán.

04

Xuất bản Pages

Chọn GitHub Actions trong Settings → Pages. Workflow kiểm tra và xuất bản tự động.

Có thể thanh toán và giao code tự động không?

GitHub Pages phục vụ giao diện tĩnh. Giao dịch thật cần API tạo đơn, xác minh webhook thanh toán, xác thực và kho file riêng. Xem docs/COMMERCE.md.

Tôi có thể dùng starter miễn phí cho dự án thương mại?

Ba starter đi kèm được phát hành theo MIT. Giữ thông báo bản quyền và giấy phép khi phân phối. Các sản phẩm trả phí hiện là minh họa.

Làm sao đưa sản phẩm của tôi vào cửa hàng?

Chuẩn bị ảnh, demo, tài liệu, giấy phép và gói nguồn. Sửa data/products.json theo docs/SELLER.md; không đưa mã nguồn trả phí vào repo công khai.
